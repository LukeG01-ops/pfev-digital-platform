# Shift Flow — direction contract

Mode: book-led editorial experience; Operate in the planner.

THESIS: A coherent literary world, centered on the books and on living with changing energy. The platform supports the method; technical details are secondary and collapsed.

OWN-WORLD: White-paper ground, soft charcoal-green text, coral accents, rose and aqua from Shift Flow, blue from Evolve. Bodoni Moda display typography echoes the serif lettering of Relactions and Evolve; Barlow is the readable interface face.

STORY: Recognize a lived problem, explore the original books in order, learn the method through examples, create a flexible plan, then optionally inspect the technical implementation.

FIRST VIEWPORT: Large serif headline at left; a 3D book with actual cover, pointer tilt, rotation slider and opening cover at right. Three-volume selector changes the cover, synopsis and atmosphere. No hero chart.

FORM: The user explicitly chose the new aesthetic and book-led direction. Build directly in the existing Vite stack. CSS transforms make the interactive book geometry; the actual user-provided cover is the front texture. Spine and inner page are illustrative.

FINISH: Validate source and state transitions, preserve both services and the safe Markdown boundary, package a standalone interactive preview, and report visual browser verification as incomplete until the environment allows it.
